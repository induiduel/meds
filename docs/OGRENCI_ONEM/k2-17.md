Soru tipleri:

- **Hasarın yerine göre polinöropati tipleri: nöronopati (sinir hücre gövdesi), aksonopati, miyelinopati (AIDP/GBS, KIDP), mononöropati multipleks, basit mononöropati (karpal tünel):** tanım → ad: sinir hücre gövdesinde (soma) hasar → nöronopati (çeldirici aksonopati, miyelinopati, nöropati, radikülopati); örnek → tip: karpal tünel → basit mononöropati; PAN'a bağlı asimetrik çok sinir tutulumu → mononöropati multipleks; vaka: aşağıdan yukarı ilerleyen akut demiyelinizan felç, solunum yetmezliği → Guillain-Barré
- **Periferik sinir yaralanma paternleri: Waller dejenerasyonu, segmental demiyelinizasyon, aksonal dejenerasyon (dying back):** tanım → ad: distalde akson + miyelin parçalanması, makrofaj fagositozu → Wallerian dejenerasyon (çeldirici segmental demiyelinizasyon, dying back, aksonotmezis, nöronopati); aksonal nöropatide akson için tipik olan → distal Waller + sekonder miyelin kaybı; prognoz karşılaştırması: en iyi segmental demiyelinizasyon, en kötü aksonal dejenerasyon
- **Pozitif ve negatif duyusal fenomenler; kalın miyelinli / ince miyelinsiz lif tutulumu; eldiven-çorap duyu kaybı:** hangisi negatif fenomendir → ağrısız yanma/travma (çeldiricilerin hepsi pozitif fenomen); lif tipi → bulgu: ince miyelinsiz lif kaybı → ağrı-ısı kaybı; ağrılı polinöropatinin en sık nedeni → diyabetik polinöropati
- **Seddon ve Sunderland sınıflaması: nöropraksi, aksonotmezis, nörotmezis:** tanım → derece: miyelin hasarlı, akson sağlam → nöropraksi; ters yön: endonöral tüp, perinöryum ve epinöryum ağır hasarlı → nörotmezis
- **Sinir lifi tipleri A / B / C: çap, miyelin, işlev, ileti hızı:** hangisi miyelinsizdir → Tip C (çeldirici Tip A, Tip B, kalın lifler); sayı: en yavaş ileti → Tip C (<2 m/sn)
- **Polinöropatiye eşlik eden bulgular: VII. kraniyal sinir tutulumu ve piramidal bulgu ile giden hastalıklar:** polinöropati + fasiyal parezi → GBS / Lyme / sarkoidoz; polinöropati + piramidal bulgu → B12 eksikliği
- **Diğer seçilen yerler: Romberg ve trofik değişiklikler, motor muayene (kas erimesi aksonalda var):** kas erimesi aksonal / demiyelinizan ayrımı
- **Notta yok, sorulmuş: miyastenia gravis ve nöromüsküler kavşak hastalıkları (büyük olasılıkla ayrı bir dersin içeriği):** yanlış bul: MG'de hedef presinaptik kalsiyum kanalı (yanlış; hedef postsinaptik AChR); olumsuz kök: hangisi kavşak hastalığı değildir → GBS (çeldirici MG, Lambert-Eaton, konjenital miyastenik sendromlar)
