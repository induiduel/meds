# Arşiv: tek seferlik betikler

Bu klasördeki betikler hiçbir servis, faz zinciri adımı, package.json betiği, sunucu ya da yönetim panelinin
betik listesi tarafından çağrılmıyor (2026-10-07 taraması). Çoğu bir kez çalıştırılıp çıktısı veritabanına alınmış
deste/özet/soru üreticileridir. Silinmedi; gerektiğinde buradan incelenebilir. Göreli yol kullanan bir betiği
yeniden çalıştırmadan önce yolları kontrol edin.
